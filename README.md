 # Simple Calculator

A small Python program that performs basic arithmetic operations
(add, subtract, multiply, divide).

## How to Run

1. Make sure Python is installed.
2. Open this folder in VS Code.
3. Run in terminal:

   python main.py

## Example

Enter first number: 10
Enter second number: 5
Choose operation (+, -, *, /): +
Result: 15.0
